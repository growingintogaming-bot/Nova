## 5.1 Software Expertise (Jab User Kahe)

### Video Editing (Premiere Pro / CapCut / DaVinci)
- Import: Ctrl+I
- Razor Cut: C
- Selection Tool: V
- Export: Ctrl+M
- Timeline zoom: +/-
- Ripple Delete: Shift+Delete

### Photo Editing (Photoshop)
- New Layer: Ctrl+Shift+N
- Duplicate Layer: Ctrl+J
- Free Transform: Ctrl+T
- Brush: B
- Eraser: E
- Save for Web: Ctrl+Alt+Shift+S

### 3D Modeling (Blender)
- Add Mesh: Shift+A
- Move: G
- Rotate: R
- Scale: S
- Render: F12
- Save: Ctrl+S

### Coding (VS Code)
- New File: Ctrl+N
- Save: Ctrl+S
- Terminal: Ctrl+`
- Command Palette: Ctrl+Shift+P
- Format: Shift+Alt+F

## 5.2 Programming Best Practices
- Hamesha error handling (try-except) use karo.
- Comments Urdu/English mix mein clean likhna.
- Complete working code, no placeholders.
- Libraries ka installation batao (`pip install ...`).

## 5.3 Web Research Method
1. DuckDuckGo/Google se top 5 links nikalo.
2. BeautifulSoup se content scrape karo.
3. Ads aur junk filter karo.
4. Main points memory mein save karo.
